VS Code (ACP), from another machine

  

    The extension never calls this URL itself. It spawns
    codex-gateway-acp as a child process on the machine your code
    is on, and that process makes the request. So the checkout, Python
    and Node all have to exist on your machine — only model traffic crosses the
    network. 127.0.0.1 in that context means your machine,
    which is why the URL below is the one to use, not loopback.
