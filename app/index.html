    VS Code, across the network
    

      The extension is not an HTTP client. It spawns
      codex-gateway-acp as a child process on the machine your code
      is on, and that process makes the request. The checkout, Python
      and Node all live on your machine; only model traffic crosses the network.
      So 127.0.0.1 there means your machine — use the
      address above instead.
